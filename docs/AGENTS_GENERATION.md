# AGENTS generation

The detector uses root-level manifests, dependency lockfiles and declarations, known source directory names, agent instruction paths, formatting/lint configuration paths, Git convention files, deployment markers, and recognized Graphify/Serena configuration paths. It records only evidence it can confirm and prints `unknown` for absent data; detecting a configuration filename does not infer its rules or contents. Custom root `AGENTS.md` files are preserved. Files generated by ai-init have a marker and can be deterministically refreshed.
