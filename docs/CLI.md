# CLI

Run `ai-init help` for command syntax. `setup --path DIR` selects a repository. `--dry-run` displays planned artifact operations and reports validation as skipped. `--diff` is a non-mutating dry-run that also shows a unified diff for proposed managed `AGENTS.md` changes; unmarked custom files are preserved and reported without a replacement diff. `agents generate|sync --diff` provides the same instruction-only preview. A real setup verifies that selected output files exist and that `AGENTS.md` is non-empty with valid managed markers, if present. `--with` accepts `agents`, `memory`, `worktrees`, and `gitattributes`. The gitattributes component only creates a managed file when none exists and preserves unmarked custom attributes. It never runs checkout or renormalization commands; adding attributes does not rewrite current working-tree bytes. `agents audit` and `agents validate` distinguish non-empty custom instructions from a valid managed block and reject empty or malformed files. `analyze` and `doctor` do not modify the repository. `prompt agents --output PATH` exports a bundled standalone prompt and refuses to overwrite an existing file.
