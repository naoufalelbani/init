# CLI

Run `ai-init help` for command syntax. `setup --path DIR` selects a repository. `--dry-run` displays planned artifact operations and reports validation as skipped. A real setup verifies that selected output files exist and that `AGENTS.md` is non-empty with valid managed markers, if present. `--with` accepts `agents`, `memory`, and `worktrees`. `agents audit` and `agents validate` distinguish non-empty custom instructions from a valid managed block and reject empty or malformed files. `analyze` and `doctor` do not modify the repository. `prompt agents --output PATH` exports a bundled standalone prompt and refuses to overwrite an existing file.
