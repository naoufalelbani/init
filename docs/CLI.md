# CLI

Run `ai-init help` for command syntax. `setup --path DIR` selects a repository. `--dry-run` displays planned artifact operations and reports validation as skipped. `--diff` is a non-mutating dry-run that also shows a unified diff for proposed managed `AGENTS.md` changes; unmarked custom files are preserved and reported without a replacement diff. `agents generate|sync --diff` provides the same instruction-only preview. A real setup verifies that selected output files exist and that `AGENTS.md` is non-empty with valid managed markers, if present. `--with` accepts `agents`, `memory`, `worktrees`, `gitattributes`, and `hooks`. The gitattributes component creates a managed file only when none exists and the Git index is empty; tracked repositories are skipped to avoid making existing files appear modified. Unmarked custom attributes are preserved. It never runs checkout or renormalization commands. The hooks component installs only when the standard Git hooks path is in use, no `pre-commit` hook exists, and `ai-init` is on `PATH`; custom hooks and `core.hooksPath` are preserved. `ai-init hooks check-staged` checks staged additions for high-confidence credential formats, unresolved conflict markers, a designated unsafe-placeholder sentinel, and task-local ai-init metadata. It does not scan unstaged working-tree content. Git hooks are local safeguards, not security boundaries. `agents audit` and `agents validate` distinguish non-empty custom instructions from a valid managed block and reject empty or malformed files. `analyze` and `doctor` do not modify the repository. `prompt agents --output PATH` exports a bundled standalone prompt and refuses to overwrite an existing file. `wt open TASK --ide ADAPTER` launches supported tools from the matching `agent/TASK` worktree; see the [worktree guide](WORKTREES.md) for supported launchers and limitations.
