# Security

ai-init runs local Git commands and writes generated files under the selected repository. It does not call cloud APIs. Review generated artifacts before committing or sharing. Do not place credentials in project context. Optional `setup --with hooks` installs a local `pre-commit` safeguard only when Git uses its standard hooks directory, no hook already exists, and `ai-init` is available on `PATH` to Git. The hook inspects staged additions for high-confidence credential patterns, conflict markers, a dedicated unsafe-placeholder sentinel, and task-local ai-init metadata. It does not inspect unstaged content, may not recognize every secret format, and can be bypassed. Existing hooks and custom `core.hooksPath` settings are preserved. Worktree cleanup does not remove dirty or unintegrated branches.
